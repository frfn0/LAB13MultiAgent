## Структура проекта

```
.
├── go.mod                      Go-модуль агентов
├── docker-compose.yml          NATS в контейнере
├── agents/
│   ├── classifier/             агент классификации тикетов
│   ├── knowledge/              агент поиска по базе знаний
│   ├── responder/              агент генерации ответов
│   └── escalation/             агент эскалации
├── orchestrator/               оркестратор на Python (asyncio + nats-py)
├── api/                        REST API на FastAPI
├── knowledge_base/             база знаний техподдержки
├── tests/                      тесты Go и Python
└── results/                    фактический вывод запусков
```

Инструкции по заданиям появятся здесь по мере выполнения.
